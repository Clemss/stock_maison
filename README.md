# Stock Maison

Appli web (installable sur iPhone) pour suivre le stock du frigo, des congélateurs et des placards, partagée entre deux téléphones.

- `index.html`, `css/`, `js/` : l'appli
- `config.js` : URL et clé anon Supabase (vides = mode démo)
- `supabase/schema.sql` : base de données à coller dans le SQL Editor de Supabase
- `docs/Guide-installation-Stock-Maison.pdf` : installation pas à pas

Hébergement : GitHub Pages (Settings › Pages › branche `main`, dossier racine).
